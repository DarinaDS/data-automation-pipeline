# Data Automation Pipeline

Автоматизированный Python-скрипт для обработки данных, анализа, обучения ML-моделей и автоматической генерации отчетов.

## Функционал
- **Загрузка данных:** Поддержка CSV, Excel, SQL-баз данных и REST API.
- **Очистка данных:** Обработка пропущенных значений, удаление дубликатов, обработка выбросов (IQR), кодирование категорий.
- **Анализ и ML:** Расчет базовых статистик и обучение модели регрессии (`RandomForestRegressor`).
- **Отчетность:** Генерация отчетов в форматах Excel, PDF и сохранение графиков.

## Документация по функциям модулей

Модуль src/data_loader.py - Загрузка данных
Предназначен для извлечения данных из различных источников.

load_csv(file_path)
Описание: Загружает данные из локального CSV-файла.
Параметры: file_path - путь к CSV-файлу.
Возвращает: датасет DataFrame.
Пример использования: df = load_csv("data/sales_data.csv")

load_from_api(url)
Описание: Выполняет запрос к внешнему REST API и преобразует ответ.
Параметры: url - адрес API.
Возвращает: датасет DataFrame.
Пример использования: df_api = load_from_api("https://jsonplaceholder.typicode.com/posts")

load_from_sql(query, db_connection)
Описание: Выполняет SQL-запрос к базе данных.
Параметры: query - текст SQL-запроса, db_connection - подключение к базе данных.
Возвращает: результат выполнения запроса в виде DataFrame.

Модуль src/data_cleaner.py - Очистка и валидация
Отвечает за предобработку данных, удаление дубликатов, пропусков и выбросов.

clean_data(df)
Описание: Проводит комплексную очистку датасета.
Параметры: df - исходный датасет.
Возвращает: очищенный датасет.
Пример использования: df_clean = clean_data(df)

remove_outliers_iqr(df, column)
Описание: Удаляет выбросы из числовой колонки методом межквартильного размаха.
Параметры: df - датасет, column - название колонки.
Возвращает: датасет без выбросов.

Модуль src/analyzer.py - Анализ данных и ML
Выполняет расчёт базовой статистики и обучение модели.

analyze_data(df)
Описание: Рассчитывает сводную статистику.
Параметры: df - очищенный датасет.
Возвращает: словарь с метриками.

train_model(X, y)
Описание: Обучает модель RandomForestRegressor для прогнозирования.
Параметры: X - матрица признаков, y - целевая переменная.
Возвращает: обученную модель и метрики качества.
Пример использования: model, metrics = train_model(X, y)

Модуль src/reporter.py - Генерация отчётов
Сохраняет результаты анализа в файлы.

generate_excel_report(df, output_path)
Описание: Сохраняет данные в Excel-файл.
Параметры: df - данные, output_path - путь к файлу.

generate_pdf_report(stats, output_path)
Описание: Генерирует итоговый отчёт в формате PDF.
Параметры: stats - результаты анализа, output_path - путь к файлу.

save_charts(df, output_dir)
Описание: Создает и сохраняет графики.
Параметры: df - датасет, output_dir - папка для сохранения.
