# Data Automation Pipeline

Автоматизированный Python-скрипт для обработки данных, анализа, обучения ML-моделей и автоматической генерации отчетов.

## Функционал
- **Загрузка данных:** Поддержка CSV, Excel, SQL-баз данных и REST API[cite: 1].
- **Очистка данных:** Обработка пропущенных значений, удаление дубликатов, обработка выбросов (IQR), кодирование категорий[cite: 1].
- **Анализ и ML:** Расчет базовых статистик и обучение модели регрессии (`RandomForestRegressor`)[cite: 1].
- **Отчетность:** Генерация отчетов в форматах Excel, PDF и сохранение графиков[cite: 1].
